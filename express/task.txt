Задание 1

Давайте создадим проект Node.js и установим в него Express.js.

1.	Создайте новый проект Node.js:

Откройте терминал (или командную строку).
Создайте новую директорию для вашего проекта и перейдите в неё:
Инициализируйте новый проект Node.js: npm init -y

2.	Установите Express.js:

Используйте npm для установки Express.js: npm install express
После установки Express.js будет добавлен в зависимости вашего проекта, и вы сможете его использовать для создания сервера.Создайте файл `index.js`.

Откройте файл `package.json` и добавьте следующий фрагмент для использования модулей ECMAScript: "type": "module"

Импортируйте Express и создайте экземпляр приложения.

Настройте маршрут для обработки GET запросов к корневому маршруту (`/`), который будет возвращать строку "Hello, World!".

Настройте сервер на прослушивание порта 3000 и запустите его.

Откройте браузер и перейдите по адресу `http://localhost:3000`, чтобы увидеть сообщение "Hello, World!".
