Создайте HTTP сервер для загрузки и скачивания больших файлов с использованием потоков (streams). Сервер должен поддерживать заголовок Cache-Control для скачивания и проверку API ключа.
Требования:

1. Создайте проект fileTransferServer и файл server.js
2. Импортируйте модули http, fs, path, events
3. Создайте экземпляр EventEmitter
4. Зарегистрируйте обработчики событий:
   downloadStart – выводит в консоль "[ЗАГРУЗКА] Начата загрузка файла"
   downloadComplete – выводит в консоль "[ЗАГРУЗКА] Загрузка завершена"
   uploadStart – выводит в консоль "[ОТПРАВКА] Начата отправка файла на сервер"
   uploadComplete – выводит в консоль "[ОТПРАВКА] Отправка завершена"
   uploadProgress – выводит в консоль каждые 1 МБ прогресс отправки
5. Создайте HTTP сервер со следующими маршрутами:
   GET /download/{filename} – скачивает файл с сервера. Использует поток fs.createReadStream. Устанавливает заголовок Content-Disposition: attachment чтобы браузер скачивал файл. Устанавливает заголовок Cache-Control: public, max-age=3600
   POST /upload/{filename} – загружает файл на сервер. Использует поток fs.createWriteStream. Принимает данные из req и записывает в файл
   GET /stream/{filename} – стримит файл (видео/аудио) с поддержкой частичных запросов (заголовок Range). Поддерживает заголовок Range: bytes=0-1024
6. Все маршруты требуют API ключ в заголовке X-API-Key: my-secret-key-2024
7. Если API ключ неверен или отсутствует, возвращайте статус 403
8. Запустите сервер на порту 3333
